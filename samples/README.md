# Samples

All samples compile and run with T0. Sources and JSON cases stay separate.

- [001-bindings.mini](001-bindings.mini): Binding initialization and cursor assignment. [Cases](../cases/language/003-002-bindings-sample.case.json).
- [002-expressions.mini](002-expressions.mini): Arithmetic, comparison, booleans, and text concatenation. [Cases](../cases/language/015-002-expressions-sample.case.json).
- [003-io.mini](003-io.mini): Copy stdin to stdout. [Cases](../cases/language/005-002-io-sample.case.json).
- [004-text.mini](004-text.mini): Scan text and replace tabs and newline characters with spaces. [Cases](../cases/language/019-004-text-sample.case.json).
- [005-file.mini](005-file.mini): Copy a file and print its content. [Cases](../cases/language/021-003-file-sample.case.json).
- [006-list.mini](006-list.mini): Pass an argument list to a function and join its elements. [Cases](../cases/language/024-003-list-sample.case.json).
- [007-exit.mini](007-exit.mini): Exit with status 2 when an argument is missing. [Cases](../cases/language/025-004-process-exit-sample.case.json).
- [008-diagnostic.mini](008-diagnostic.mini): Write a diagnostic before an unsuccessful exit. [Cases](../cases/language/026-003-write-error-sample.case.json).
- [010-map.mini](010-map.mini): Use `map_new`, `map_set`, `map_has`, and `map_length`; replacing a value keeps the key count unchanged. [Cases](../cases/language/033-005-map-sample.case.json).
