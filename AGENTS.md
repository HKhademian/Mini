# Working on MiniLang

These instructions apply to the entire repository.

- Read [the project direction](README.md) before changing language scope.
- Follow [atomic commits](.agents/rules/atomic-commits.md) for every change.
- Follow [development guidance](.agents/rules/development.md) for compiler,
  tooling, documentation, and release work.
- Keep instructions here and in `.agents/rules/` authoritative. Editor rules
  should point here rather than copy them.
