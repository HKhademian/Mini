# Mini libraries

- `core/` — shared path, text, list, JSON, process, numeric, value, and
  play-session APIs. `process.mini` defines core process APIs.
- `compiler/` — compiler implementation parts included by
  `tools/compiler.mini`.
- `util/` — optional helpers such as process capture, line output, project
  paths, native artifact paths, result maps, and the Mini Play pixel-board
  builder.
- `tools/` — behavior libraries for command entries under `tools/`.
