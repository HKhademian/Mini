# Mini libraries

- `core/` — shared path, text, list, JSON, process, result, value,
  numeric, and play-session libraries. `process.mini` defines core process
  APIs; `util/process.mini` provides capture and text-stream helpers.
- `compiler/` — compiler implementation parts included by
  `tools/compiler.mini`.
- `util/` — optional helpers such as process capture, line output, project
  paths, native artifact paths, and the Mini Play pixel-board builder.
- `tools/` — behavior libraries for command entries under `tools/`.
