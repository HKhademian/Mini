# Mini libraries

- `core/` — shared path, text, list, JSON, process, numeric, and value APIs.
  `process.mini` defines the core process calls.
- `compiler/` — compiler implementation parts included by
  `tools/compiler.mini`.
- `util/` — optional helpers such as process capture, line output, project
  paths, native artifact paths, result maps, canvas session state, and the
  Mini Play pixel-board builder.
- `tools/` — behavior libraries for command entries under `tools/`.
